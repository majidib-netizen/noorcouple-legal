3. Objet

NoorCouple est une application mobile destinée aux couples musulmans, proposant :

  • Un parcours personnalisé de 40 jours pour renforcer le couple

  • Des fiches conjugales et défis de la semaine
  • Un mode crise pour les moments difficiles
  • Un mode duo pour partager le parcours avec son conjoint(e)

Le mode Duo permet à deux conjoints de partager leurs parcours. L'utilisateur principal génère un code unique (format NOOR-XXXXXX) qu'il partage avec son conjoint(e).

L'éditeur ne consulte pas le contenu de vos réponses dans le cadre de l'exploitation normale du service.
